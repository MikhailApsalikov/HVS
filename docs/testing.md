# Тестирование

`pnpm check` — обязательная проверка перед передачей изменений. GitHub Actions запускает ту же команду. Для первого запуска нужно установить Chromium: `pnpm exec playwright install chromium`. Можно использовать установленный Chrome через `PLAYWRIGHT_CHANNEL=chrome`.

## Карта проверок

| Область                                                                                                           | Где проверяется                                                       |
| ----------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Все стадии формулы, пример 37, порядок источников, границы, нечисловые значения                                   | `tests/numbers.test.ts`                                               |
| Ранги одного таланта, разные таланты, совместные предметы, защита, новые характеристики                           | `tests/rules.test.ts`                                                 |
| Каждый предмет, цена и преобразование бонусов                                                                     | Параметризованные сценарии в `tests/rules.test.ts`                    |
| Стрельба, энергия, столкновения, шесть видов пауков, награды, все восемь способностей                             | `tests/session.test.ts`                                               |
| Уровни, очки, ограничения команд, покупка/продажа, поражение                                                      | `tests/session.test.ts`                                               |
| Полное сохранение и восстановление, миграции 1/2, повреждённые данные, недоступное хранилище                      | `tests/save.test.ts`                                                  |
| Частота кадров, повторный запуск, соединение UI и ядра, актуальные подсказки                                      | `tests/adapters.test.ts`                                              |
| Отсутствие зависимостей ядра от браузера и мутаций из UI                                                          | `tests/architecture.test.ts`                                          |
| Сохранность исходных имён, ID и цен всех предметов, базового баланса и аудио                                      | Независимый снимок старой версии `tests/fixtures/legacy-content.json` |
| Полный путь через готовую сборку: меню → талант → магазин → бой → сохранение → загрузка, клавиатура и способности | `tests/browser/game.spec.ts`                                          |

## Правила для дальнейших изменений

Новое поведение требует проверки через публичные команды `GameSession`, а исправление ошибки — регрессионного сценария. Не следует ограничиваться тестом внутреннего вспомогательного метода. Случайность подставляется через конструктор сессии, время продвигается явно, браузер для тестирования правил не нужен.

Для новых/изменённых пользовательских действий добавляется браузерный сценарий. Новая версия сохранения требует примера прежнего формата и проверки миграции. При намеренном изменении каталога или исходного баланса обновляется соответствующая независимая контрольная запись вместе с описанием изменения.

Порог покрытия исполняемого ядра, управления игрой, цикла и сохранений: минимум 90% строк, выражений и функций, 80% ветвей. Проверка завершается ошибкой при падении ниже порога. Сам процент не заменяет сценарии поведения. Визуальное оформление и аудио не входят в этот процент; браузерные сценарии проверяют пользовательские действия, а снимок каталога — наличие всех звуков.
