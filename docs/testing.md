# Тестирование

`pnpm check` — обязательная проверка перед передачей изменений. GitHub Actions запускает ту же команду. В проекте только юнит-тесты Vitest; установка браузера не нужна.

## Правила для дальнейших изменений

Новое поведение требует проверки через публичные команды `GameSession`, а исправление ошибки — регрессионного сценария. Не следует ограничиваться тестом внутреннего вспомогательного метода. Случайность подставляется через конструктор сессии, время продвигается явно, браузер для тестирования правил не нужен.

Новая версия сохранения требует примера прежнего формата и проверки миграции. При намеренном изменении каталога или исходного баланса обновляется соответствующая независимая контрольная запись вместе с описанием изменения.

Порог покрытия исполняемого ядра, управления игрой, цикла и сохранений: минимум 90% строк, выражений и функций, 80% ветвей. Проверка завершается ошибкой при падении ниже порога. Сам процент не заменяет сценарии поведения. Визуальное оформление и аудио не входят в этот процент; снимок каталога проверяет наличие всех звуков.
