# Android

Android — отдельный интерфейс той же игры. Телефон и поле вертикальные: девять дорожек слева направо, пауки сверху вниз, лучники снизу. Стрельба — панель 3 × 3, способности — 3 × 4 рядом. Экран боя не прокручивается. Остальные экраны используют вертикальные списки и карточки.

## Общие исходники

- `packages/game` предоставляет Android доступ к существующим `src/domain` и `src/content`. Числа, бой, таланты, предметы и миграции не копируются.
- `src/presentation` содержит общие описания и фильтры каталога. Web сохраняет совместимые импорты через реэкспорты `src/ui`.
- `src/assets` содержит общий генератор иллюстраций предметов. Исходные SVG и звук остаются в `src/sprites`.
- `scripts/mobile-assets.mjs` генерирует карту ресурсов для Metro. Генерируемые файлы не коммитятся.
- `src/application/MobileGameController.ts` связывает публичные команды сессии, ввод, фиксированное время и жизненный цикл. В нём нет формул боя.
- `src/infrastructure/storage/MobileSaveStore.ts` хранит две чередующиеся записи с монотонным номером. В каждой — рекорд и сохранение общего формата либо отметка завершённой партии. Неизвестный будущий формат блокирует перезапись.
- `apps/mobile` — React Native, Hermes, Skia, нативные звук и хранилище. WebView отсутствует.

Web продолжает собираться Vite. Android импортирует то же ядро через workspace-пакет `@hvs/game`; отдельной ветки правил нет. Выпущенные версии Android фиксируются тегами/коммитами. Изменение сайта не обновляет установленный APK: выпускается новая версия приложения.

## Локальные команды

Требуются Node 24+, pnpm из `package.json`, JDK 17, SDK 36, Build Tools 36.0.0, NDK 27.1.12297006 и CMake 3.22.1. Минимальная версия приложения — Android 7 / API 24; целевой API — 36. Поддерживаются ARM64 и x86_64.

```powershell
pnpm install --frozen-lockfile
pnpm check
pnpm mobile:bundle
```

На Windows `scripts/android-setup.ps1` устанавливает инструменты в игнорируемую папку `.android-tools`. Установка предоставляет просмотр лицензий SDK. Если Java и SDK уже установлены, достаточно `JAVA_HOME` и `ANDROID_HOME`.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/android-setup.ps1
pnpm mobile:apk
```

Результат: `apps/mobile/android/app/build/outputs/apk/preview/app-preview.apk`. Это автономная оптимизированная сборка с локальной отладочной подписью и идентификатором `com.hvs.game.preview`. Metro, подключение к компьютеру и интернет для игры не нужны. Предварительная сборка устанавливается отдельно от будущего выпуска для магазинов.

Для разработки с Metro: `pnpm mobile:start`; в другом терминале с настроенным Android окружением — `pnpm --filter @hvs/mobile android`.

## Проверки

`pnpm check` генерирует общие ресурсы Android, проверяет оба TypeScript-проекта, форматирование, юнит-тесты, покрытие и Web-сборку. Пороги покрытия сохранены. `tests/mobile.test.ts` проверяет ввод через сессию, одинаковое поведение при разных частотах кадров, остановку и восстановление, очередность записей, повреждение сохранений и предыдущий формат.

Workflow `Android preview` собирает APK по запросу или в PR с изменениями игры. Он не публикует приложение. Доступность и фактическую работу workflow подтверждает только успешный запуск в GitHub.

Перед передачей пользователям нужна ручная проверка установленной сборки: узкий и обычный телефон, касания двумя пальцами, высокие уровни, все способности, переходы, сворачивание, принудительное завершение, установка обновления поверх предыдущей версии, звук, шрифты и системные отступы. Производительность оценивается на устройстве в сборке preview/release; успешная компиляция не подтверждает 60 FPS.

## Выпуск в магазины

Для Google Play предусмотрен `pnpm mobile:aab`. Настройки подписи передаются через `HVS_KEYSTORE`, `HVS_STORE_PASSWORD`, `HVS_KEY_ALIAS`, `HVS_KEY_PASSWORD`. Без них сценарий отказывается собирать выпуск. Ключи и пароли не хранятся в репозитории. Для RuStore доступна подписанная задача Gradle `:app:assembleRelease`; схема подписи должна быть согласована для обоих магазинов.

До первой публикации необходимо закрепить окончательный идентификатор, владение ключом, заполнить карточки магазинов и анкеты данных/возраста, опубликовать политику конфиденциальности, пройти тестирование и проверить актуальные требования магазинов, включая 16 КБ страницы памяти нативных библиотек. Игровой выпуск не запрашивает разрешение на интернет; оно есть только в отладочной сборке с Metro.

Исходная музыка и звуки перенесены для предварительного тестирования. Происхождение файлов `ShaoKahn*`, `BloodElf*`, `WoW on Relax.mp3`, `Refresher_Orb.mp3` и остальных ресурсов должно быть подтверждено владельцем либо ресурсы заменены перед публикацией. Наличие файла в старой Web-версии не подтверждает лицензию. Шаблон React Native сопровождается `apps/mobile/TEMPLATE-LICENSE`.

Облачные сохранения, регистрация, реклама и платежи в эту версию не входят. Прогресс Android независим от Web. Разделение интерфейса и ядра позволяет подключать платформенные службы без изменения правил.
