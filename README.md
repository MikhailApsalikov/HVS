# Hunters versus Spiders

Браузерная игра о защите замка девятью лучниками. Три сложности, двенадцать типов пауков, способности и таланты в трёх ветках, основные характеристики и броня, полный каталог предметов, графика и звук. Правила для первого знакомства и полный справочник доступны через «Помощь» в главном меню.

## Запуск

Требуются Node.js 24+ и pnpm 11.19.0 (версия закреплена в `package.json`).

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Для production сначала соберите приложение, затем запустите его на порту 3000:

```sh
pnpm build
pnpm start
```

Клавиши 1–9 стреляют по соответствующим линиям. Q–P активируют способности; физические клавиши работают и при русской раскладке. Покупка и продажа предметов — двойным нажатием между уровнями.

## Версия игры

Главное меню показывает `3.X.Y.Z`. AI отмечает тип каждой выполненной задачи командой `pnpm version:flag <balance|cosmetic|none> <уникальный-id-задачи>`. Команда добавляет флаг в журнал `game-version.json`; X и Y считаются автоматически, ручных числовых полей нет. Владелец запускает игру и коммитит изменения как обычно.

- `balance` повышает X при изменении игровых правил или баланса, в том числе в задаче с сопутствующей косметикой.
- `cosmetic` повышает Y при изменении внешнего вида, звука или интерфейса без изменения баланса.
- `none` сохраняет X/Y для задач только с инструментами, документацией и тестами.

Например, AI выполняет `pnpm version:flag balance rebalance-hunter-talents`, а при отдельной замене звуков — `pnpm version:flag cosmetic replace-shot-sounds`. Каждая задача получает новый ID. Повтор команды с тем же ID и флагом, повторная сборка и обычный коммит не повышают X/Y повторно. Журнал хранится в Git вместе с изменениями; накопленные записи не удаляются и не переиспользуются. X и Y начинаются с 0/0 и растут независимо: повышение X не сбрасывает Y.

Z автоматически равен числу коммитов в истории HEAD и не сбрасывается при изменении X/Y. Новая сборка получает новый Z без AI и Git-хуков; запущенный `pnpm dev` сам обновляет страницу после коммита или добавления флага, меняющего X/Y. Для корректного номера нужна полная история Git; после неглубокого клонирования выполните `git fetch --unshallow`. Начальная версия — `3.0.0.Z`.

## Проверки

```sh
pnpm check
```

Одна команда проверяет типы, форматирование, юнит-тесты правил и регрессий, покрытие и производственную сборку. Эти же проверки запускаются в GitHub Actions на push и pull request. Браузер для тестов не требуется.

Отдельно доступны `pnpm test`, `pnpm test:watch`, `pnpm test:coverage`, `pnpm build` и `pnpm preview`. Покрытие сохраняется в `coverage/index.html`.
